# Mock provider — готовий

OpenAI-сумісний фейковий ендпоінт (`/v1/chat/completions`). Повертає детерміновані
відповіді й дозволяє на замовлення відтворювати збої (див. `docs/failure-scenarios.md`):
503, 429, затримку, сміття у відповіді. Використовується для dev і CI без витрат.
