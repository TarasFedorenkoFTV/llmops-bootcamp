# Лонг-ріди L01–L12: передача

Матеріали занять готові й провалідовані. Цей файл — те, що потрібно знати
тому, хто бере їх у роботу далі.

## Що передається

| Що | Де | Стан |
|---|---|---|
| 12 навчальних матеріалів занять | `L01.html` … `L12.html` | готові; self-contained (стилі inline, жодних зовнішніх залежностей), відкриваються з диска |
| Зміст курсу | [index.html](index.html) | 12 карток по тижнях |
| Навігація між заняттями | футер кожної сторінки | ← попередній · Зміст · наступний → |
| Правила формату | [STYLE.md](STYLE.md) | стиль, рубрики, обов'язкові блоки, чек-лист автора |
| Нотатки для запису відео | [PRODUCTION.md](PRODUCTION.md) | тільки для автора; на сторінках занять продакшн-інформації немає |
| Комплект заняття (файли/бранчі/ДЗ) | [../COURSE_MANIFEST.md](../COURSE_MANIFEST.md) | для того, хто публікує |

Супутнє (поза цією папкою): конспекти `docs/lessons/`, ДЗ `starter/homework/`,
[гайд ментора](../MENTOR_GUIDE.md), пре-реквізити `starter/PREREQUISITES.md`.

## Чим це перевірено

- **Формат:** усі 12 сторінок — валідний HTML, обсяг у коридорі ±15% від L01
  (2331–2704 слова), у кожній є принцип + типова помилка + лайфхак, опційні
  секції позначені бейджем, ДЗ-блок відповідає типу уроку (прев'ю / повний).
- **Факти:** кожен факт лаби відтворений **наживо** на відповідному бранчі
  еталона (`w1`…`w6`) — повний прогін по всіх тижнях, включно з демо
  «зламаний промпт → червоні evals → відкат → зелені».
- **Узгодженість:** лонг-ріди ↔ конспекти ↔ hw1–hw6 ↔ критерії ментора ↔ код
  еталонів звірені; розподіл core/optional однаковий у всіх чотирьох джерелах.
- **Чистота:** жодних згадок відео/хвилин/нотаток автора на сторінках
  студента; жодних брендів, компаній і номерів задач — досвід знеособлений.

## Правила, які тримають це в узгодженому стані

1. Факт лаби, що не відтворюється на бранчі `wN` — виправляй **еталон**, а не
   формулювання в лонг-ріді.
2. Зміна розподілу core/optional проходить одночасно по чотирьох місцях:
   конспект → лонг-рід → `hwN.md` → еталон.
3. Перед зміною сторінки — чек-лист у [STYLE.md](STYLE.md).
4. Перед записом відео уроку N — тег `video-LNN` на коміті бранча `wN`
   (розділ «Заморозка еталона» у PRODUCTION.md): після запису фікси того
   тижня ламають уже зняті кадри.

## Що лишилося поза матеріалами

Запис відео (сценарна база повна: лонг-рід = сценарій теорії, PRODUCTION.md =
покадрові демо-послідовності лаб і передумови запису) і публікація на
платформі — не зона автора матеріалів.
