# Генератори колод

Колоди зібрані скриптами, а не руками: `deck_lib2.js` — візуальний каркас
(слайд, титул, фінал, примітиви: плитки, схеми-потоки, машини станів, таймлайни,
порівняльні смуги, шари, таблиці, код, глосарій), `gen2_lNN.js` — сценарій
конкретного уроку.

## Перезбирання

```
npm install pptxgenjs
node gen2_l07.js          # → LNN.pptx + LNN-script.md
```

Шляхи виводу задані в кінці кожного `gen2_lNN.js`.

## Перевірки

- `python overlap.py L*.pptx` — геометричний детектор накладань і виходів за межі
  слайда (ловить те, що не видно в коді: смуга поверх шарів, підпис на таблиці).
- Валідація OOXML — `scripts/office/validate.py` зі скіл-набору pptx.
- Візуальний контроль — рендер через LibreOffice у PDF і перегляд сторінок.

## Начитка

Текст виступу задається полем `notes` кожного слайда і потрапляє **не в pptx**,
а в `LNN-script.md` (див. `save()` у `deck_lib2.js`). Нинішні генератори
успадковують начитку з попередньої версії колод через `decks_dump.json`; цей
дамп у репозиторій не кладеться — тексти вже зафіксовані у самих сценаріях
`docs/decks/LNN-script.md`, які і є джерелом правди для запису.
