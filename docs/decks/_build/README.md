# Генератори колод

Колоди зібрані скриптами, а не руками. `deck_lib2.js` — візуальний каркас
(титул, слайд, фінал + примітиви: плитки, потоки, машини станів, таймлайни,
порівняльні смуги, шари, таблиці, код, глосарій, чек-листи). `gen2_lNN.js` —
сценарій конкретного уроку.

## Хто чому джерело

- **Зміст слайдів** — у `gen2_lNN.js` (він же звіряється з `../../longreads/LNN.html`).
- **Начитка** — у `../LNN-script.md`. Генератор **читає** її звідти і перезаписує
  той самий файл при збиранні. Правити текст виступу треба в `.md`, не в коді.
- Порядок блоків у `.md` збігається з порядком слайдів: кожен виклик `N()`
  бере наступний блок. Додаєте слайд — додайте блок «## Слайд N · …» у сценарій.

## Перезбирання

```bash
npm install pptxgenjs          # разова залежність
node gen2_l07.js               # → ../L07.pptx і ../L07-script.md
```

Шляхи можна перевизначити змінними оточення: `DECKS_DIR` (звідки брати начитку),
`DECKS_OUT` (куди класти результат) — зручно, щоб зібрати в тимчасову теку
і порівняти з поточними файлами, нічого не зачепивши.

## Перевірки

```bash
python overlap.py ../L*.pptx   # накладання і виходи за межі слайда
```

Плюс валідація OOXML (`scripts/office/validate.py` зі скіл-набору pptx, з
`PYTHONUTF8=1`) і візуальний контроль рендером через LibreOffice.
