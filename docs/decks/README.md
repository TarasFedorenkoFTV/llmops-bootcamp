# Слайдові колоди уроків (L01.pptx…L12.pptx)

Службовий матеріал, як [PRODUCTION.md](../longreads/PRODUCTION.md): студентам не
видається, продукт курсу лишається текстовим. Колоди потрібні тому, хто **веде
заняття або записує відео**. Комплект уроку N: `../longreads/LNN.html` — джерело
змісту, `LNN.pptx` — колода, `LNN-script.md` — начитка.

Зміст простежується до лонг-ріда; демо-кадри й застереження ведучому — з
PRODUCTION; формат і структура — за корпоративним регламентом навчальних
презентацій Neoversity (v1.0).

## Структура колоди

Титул → learning outcomes (дієсловами дії) → карта уроку → **терміни уроку**
(pre-training) → блоки лонг-ріда → місток «теорія → демо» → лабораторна →
«що це довело» → «перевір себе» → антипатерни → ДЗ → підсумок і наступний крок.

Маркери активності в шапці кожного слайда: ТЕОРІЯ (absorb), ПРАКТИКА (do),
РЕФЛЕКСІЯ (connect). Опційні блоки позначені бейджем ОПЦІЙНО.

## Візуальний стандарт

Смислові схеми замість текстових карток: потоки з відгалуженнями, машини станів,
таймлайни, порівняльні смуги, шари стека, зони «видимо / невидимо», великі
цифри-акценти. Один смисловий акцент на слайд; ~70 слів тексту на слайд;
палітра функціональна (зелений — безпечне, червоний — сліпа зона й помилки,
жовтий — опційне); дві гарнітури.

## Начитка

`LNN-script.md` — повний текст виступу поблочно на кожен слайд
(«## Слайд N · назва»). Помітки `[Ведучому: …]` — граблі зі стенда (порядок
кадрів, прогрів, стани, які треба скинути перед дублем); вони для того, хто
записує, і на слайди не виносяться. У самих `.pptx` нотаток немає.

Орієнтир хронометражу: 31–38 хвилин начитки на урок, ~49 тисяч слів разом.

## Правила підтримки

- Колоди прив'язані до поточного стану лонг-рідів: якщо `LNN.html` редагується,
  відповідну колоду треба перезібрати, інакше слайди розійдуться з уроком.
- Верстка перевірялася рендером LibreOffice — перед першим записом варто один
  раз прогорнути колоду в PowerPoint (метрики шрифтів там інші).
- Правило сторінок уроку «жодних шляхів до файлів матеріалів» діє і тут:
  на слайдах лишаються тільки шляхи проєкту студента і `localhost:*`.
- Схеми, зібрані для слайдів (порівняльні смуги цін, часова смуга латентності),
  підписані як схематичні там, де точних коефіцієнтів у джерелі немає.
