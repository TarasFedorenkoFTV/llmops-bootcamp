## QA-чекліст перед публікацією заняття (проганяє той, хто публікує)

- [ ] сторінка відкривається на платформі (iframe/вкладення) без консольних помилок; мобільний рендер ок;
- [ ] `<title>`/h1 = канонічна назва заняття з таблиці вище; chain-стрічка підсвічує правильний тиждень;
- [ ] `.fnav`-навігація (← попередній · Зміст · наступний →) працює — або свідомо приховано лінк на ще не опубліковане заняття;
- [ ] усі зовнішні лінки (starter, solutions, hwN) відкриваються в анонімному браузері; бранч `wN` існує;
- [ ] ДЗ-блок сторінки сходиться з `starter/homework/hwN.md`;
- [ ] факти лаби відтворюються на тегованому коміті `video-LNN`, з якого записане відео.

## Правила виробництва

- Перед записом відео уроку N автор ставить тег `video-LNN` на коміт бранча
  `wN` (розділ «Заморозка еталона» у [PRODUCTION.md](longreads/PRODUCTION.md)).
- Передумови запису по уроках (L07/L10/L11/L12 мають підготовку) —
  у PRODUCTION.md.
- Зовнішні залежності сторінок: репозиторії `llmops-bootcamp` і
  `llmops-bootcamp-solutions` (бранчі `w1`–`w6`, demo-PR #1) мають лишатися
  публічними на весь час потоку.
