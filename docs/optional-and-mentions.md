# Optional і згадки в тексті курсу

Єдиний реєстр усього, що за межами обов'язкового core: опційні секції уроків
і їхні пари в ДЗ, теми, які курс згадує в тексті, але не будує, і те, що
свідомо поза курсом. Принцип (заявлений в уроці 1): опційне ніколи не є
передумовою обов'язкового.

## Опційні секції уроків ↔ опційні пункти ДЗ

Опційні секції в лонг-рідах позначені бейджем «опційно» (`track opt`);
опційні пункти ДЗ — розділ «Опційно (не оцінюється)» у `starter/homework/hwN.md`.

## Згадано в тексті, не будуємо

Production-теми, які виходять за 6 тижнів. Курс каже, що вони є і куди рости;
місце згадки — урок 12, блок 10 «Що далі — за межами курсу».

- **Multi-turn діалог + streaming** — урок 12, «Що далі»
- **RAG / vector** — урок 12, «Що далі» (окремий капстоун сам по собі)
- **Semantic cache продакшн-рівня** (eviction, метрики схожості, окреме сховище) — урок 12, «Що далі»; базова опційна доріжка — урок 5
- **Canary в коді** (план з уроку 11, доведений до механізму) — урок 12, «Що далі»
- **Secrets і ротація ключів** — урок 12, «Що далі»
- **Quota / rate limiting per user / per tenant** — урок 12, «Що далі»
- **Fine-tuning** — урок 12, «Що далі»

## Свідомо поза курсом

Сказано прямо, щоб не було очікувань (урок 12, блок 10):

- реальний хмарний деплой, autoscaling, мультитенантність (у нас — локальний runtime + план rollout, не деплой)

runnable gateway · prompt registry · routing + fallback · cost attribution ·
safe tool calls + human approval · reliability · маскування PII (email) ·
базова observability · golden dataset + rule-based eval runner ·
CI regression gate · **30-day rollout plan** (обов'язковий deliverable hw6 —
головний transfer-артефакт).

Усе це — на mock, без реального ключа.
