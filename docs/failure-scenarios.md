# Failure scenarios для reliability

Сценарії, які студент відтворює через mock provider (керовано) і закриває в сервісі.

| # | Сценарій | Як відтворити (mock) | Очікувана поведінка |
|---|---|---|---|
| 1 | Провайдер лежить (5xx / outage) | mock повертає 503 | fallback на наступного провайдера; інцидент у лог |
| 2 | Rate limit (429) | mock повертає 429 | retry з backoff, тоді fallback |
| 3 | Стрибок латентності | mock відповідає з затримкою | timeout-бюджет; fallback або graceful degradation |
| 4 | Погана / порожня відповідь | mock повертає сміття | валідатор ловить; retry або безпечна типова відповідь |
| 5 | Збій tool-call | mock-tool кидає помилку | ідемпотентний retry; без часткового side-effect; чиста помилка користувачу |
| 6 | Усі провайдери недоступні | усі mock-провайдери 503 | graceful degradation («зайнято, спробуйте пізніше»), без падіння сервісу |

Кожен сценарій має відповідний eval / тест, щоб поведінка не регресувала.
